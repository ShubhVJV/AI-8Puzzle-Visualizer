Algorithm #2: Depth First Search (DFS) in the 8-Puzzle State Space

Depth First Search is a fundamental uninformed search strategy that prioritizes exploration along the deepest available branch of the search tree before backtracking. This case study analyzes its mathematical properties, memory efficiency advantages, implementation mechanics using a Last-In First-Out (LIFO) stack, and practical behavioral dynamics on the 8-puzzle graph.

1. Formal State-Space Problem Formulation

The 8-puzzle problem is formalized as a 5-tuple \(\langle S, s_0, A, T, G, c \rangle\):

State Space \(S\)

All valid permutations of tiles \(\{0, 1, \dots, 8\}\) arranged on a 3×3 grid. Total permutation cardinality is \(9! = 362,880\), partitioned into two disjoint reachable components of \(181,440\) states.

Actions \(A\) & Transition \(T\)

Legal movements of the blank tile: \(A = \{\text{UP}, \text{DOWN}, \text{LEFT}, \text{RIGHT}\}\). \(T(s, a) \rightarrow s'\) swaps the blank with the adjacent tile if the target coordinate is within the 3×3 bounds.

Goal Test \(G\) & Path Cost \(c\)

Goal condition checks whether current board matches the target configuration. Each tile sliding step incurs a uniform cost \(c(s, a, s') = 1\), making path cost \(g(n) = \text{depth}(n)\).

2. Solvability & Inversion Parity Invariant

// Definition of Inversion:
An inversion is an ordered pair of tiles \((a, b)\) such that \(a > b\) and \(a\) appears before \(b\) in row-major order, excluding the blank space 0.
// Invariant Parity Theorem (3×3 Grid):
Horizontal moves shift the blank within the same row without altering relative order of other tiles (inversion count change = 0).
Vertical moves shift a tile across exactly 2 intermediate tiles, changing inversion count by \(\Delta \in \{-2, 0, +2\}\). Thus, the parity of inversions is invariant.
Solvable \(\iff \text{countInversions}(S_{\text{initial}}) \equiv \text{countInversions}(S_{\text{goal}}) \pmod 2\)
LIFO Frontier Mechanics

DFS maintains an open list structured as a Last-In First-Out (LIFO) stack. When expanding node \(u\), its valid children are pushed onto the top of the stack, ensuring that the deepest generated node is visited next.

Space Efficiency Advantage

DFS requires only linear memory \(O(b \cdot m)\), where \(b \approx 3\) is the branching factor and \(m\) is maximum search depth. It stores solely the path from root to current node plus unexpanded sibling nodes.

Cycle Detection in Graphs

In state-space graphs with reversible actions, pure tree-search DFS would trap itself in infinite cycles (swapping tiles back and forth). Graph-search DFS eliminates cycles by maintaining an explored hash set.

Non-Optimality Pitfall

DFS is non-optimal: it returns the first path discovered, which can feature dozens of redundant moves. Without depth cutoffs, it can wander arbitrarily deep into unpromising subtrees.
