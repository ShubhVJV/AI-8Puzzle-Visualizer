💡 DFS in 8-Puzzle Behavior

DFS expands nodes using a Last-In First-Out (LIFO) stack. Because the 8-puzzle graph has cycles and deep branches, graph-search cycle detection is required. DFS is uninformed and non-optimal, finding paths that are often much longer than the shortest path, but requires minimal memory per branch: \(O(b \cdot m)\).

Algorithm #2: Depth First Search (DFS) in the 8-Puzzle Problem

Depth First Search is an uninformed search strategy that always expands the deepest node in the current frontier of the search tree. Implemented using a Last-In First-Out (LIFO) Stack, the search proceeds immediately to the deepest level of the search tree, backtracking only when it hits a node with no successors or a depth cutoff.

Working Principle

Maintains an open list using a LIFO Stack. At each step, it pops the top state, checks for goal state, generates valid tile movements (Up, Down, Left, Right), and pushes non-visited child states onto the stack.

Key Advantages

Remarkable space efficiency: stores only the current branch from root to leaf, consuming linear memory \(O(b \cdot m)\). This avoids the exponential RAM exhaustion of BFS in deep state spaces.

Limitations

Non-optimal (can return paths with dozens of redundant moves). Prone to descending down infinite or excessively deep branches in cyclic state graphs unless cycle detection and depth guards are used.

Complexity
Time: \(O(b^m)\)
Space: \(O(b \cdot m)\)
Completeness: With Graph Set
Optimality: Non-optimal

Mathematical Modeling & Inversion Parity Proof

The 8-puzzle state space consists of \(9! = 362,880\) permutations of tiles 0 through 8. However, exactly half (\(181,440\)) of these states are reachable from any given configuration due to inversion parity invariants:

// Inversion Definition:
An inversion is a pair of tiles \((a, b)\) such that \(a > b\) and \(a\) precedes \(b\) in row-major order (blank tile 0 excluded).
// Solvability Theorem for 3x3 Puzzle:
A configuration \(S_{init}\) can reach goal \(S_{goal}\) if and only if:
countInversions(\(S_{init}\)) mod 2 == countInversions(\(S_{goal}\)) mod 2

Full Comparative Documentation (6 Search Algorithms)

1. Breadth First Search (BFS)

Explores states level by level using a FIFO Queue. Expands all nodes at depth \(d\) before any node at depth \(d+1\).

  • Completeness: Yes (if branching factor \(b\) is finite)
  • Optimality: Yes (for uniform step costs)
  • Time Complexity: \(O(b^d)\)
  • Space Complexity: \(O(b^d)\) - memory bottleneck

2. Depth First Search (DFS) ⭐ Assigned

Explores deepest branch first using a LIFO Stack. Employs visited set to prevent infinite cycles in 8-puzzle graph.

  • Completeness: Complete in finite state spaces with graph search
  • Optimality: Non-optimal
  • Time Complexity: \(O(b^m)\)
  • Space Complexity: \(O(b \cdot m)\) - exceptionally compact

3. Depth Limited Search (DLS)

DFS bounded by a predetermined depth limit \(l\). Prevents infinite descent down deep or endless branches.

  • Completeness: Incomplete if solution depth \(d > l\)
  • Optimality: Non-optimal
  • Time Complexity: \(O(b^l)\)
  • Space Complexity: \(O(b \cdot l)\)

4. Iterative Deepening Search (IDDLS)

Iteratively executes DLS for limit \(l = 0, 1, 2, ... d\). Combines BFS optimality with DFS space efficiency.

  • Completeness: Complete
  • Optimality: Optimal for unit step costs
  • Time Complexity: \(O(b^d)\)
  • Space Complexity: \(O(b \cdot d)\)

5. Greedy Best First Search (GBFS)

Informed search expanding the node estimated to be closest to the goal using heuristic \(f(n) = h(n)\).

  • Heuristics: Misplaced Tiles \(h_1\), Manhattan Distance \(h_2\)
  • Optimality: Non-optimal
  • Time Complexity: \(O(b^m)\)
  • Space Complexity: \(O(b^m)\)

6. A* Search

Informed search evaluating nodes by total estimated path cost \(f(n) = g(n) + h(n)\). Both complete and optimal when \(h\) is admissible.

  • Heuristic Consistency: Manhattan distance dominates Misplaced tiles
  • Optimality: Optimal
  • Time Complexity: \(O(b^d)\)
  • Space Complexity: \(O(b^d)\)
